<h3>Введение и Базовое определение</h3>

<p>
  <span class="accent">Функция высшего порядка (Higher-Order Function, HOF)</span> — это функция, которая принимает одну или несколько других функций в качестве аргументов, либо возвращает другую функцию в качестве результата (или делает и то, и другое одновременно).
</p>

<p class="info info--blue">
  Такой подход стал возможным благодаря тому, что в JavaScript функции являются "объектами первого класса" (First-Class Citizens). Это означает, что с ними можно работать так же, как с обычными переменными (числами, строками, объектами). Концепция HOF лежит в самой основе функционального программирования.
</p>

<hr />

<h3>Примеры кода</h3>

<h4>Пример 1: Функция принимает другую функцию как аргумент (Коллбэк)</h4>
<p>Самый базовый и частый пример — встроенные методы массивов или передача своей функции вычисления:</p>
<code class="code">
  function doOperation(a, b, operationCallback) {
    // operationCallback — и есть переданная функция
    return operationCallback(a, b);
  }

  const add = (x, y) => x + y;
  const multiply = (x, y) => x * y;

  console.log(doOperation(5, 3, add)); // 8
  console.log(doOperation(5, 3, multiply)); // 15
</code>

<h4>Пример 2: Функция возвращает другую функцию</h4>
<p>Этот подход часто используется для замыканий и фабрик функций (например, при каррировании):</p>
<code class="code">
  function multiplyBy(factor) {
    // Возвращаем новую анонимную функцию
    return function(number) {
      return number * factor;
    };
  }

  const double = multiplyBy(2);
  const triple = multiplyBy(3);

  console.log(double(5)); // 10
  console.log(triple(5)); // 15
</code>

<h3>Ключевые особенности и применение</h3>

<ul>
  <li>
    <strong>Инкапсуляция и абстракция логики:</strong> HOF позволяют абстрагировать повторяющуюся логику. Например, цикл обхода массива зашит "под капот" метода <code>Array.prototype.map</code>, и нам не нужно каждый раз писать рутинный <code>for</code>.
  </li>
  <li>
    <strong>Композиция и Декораторы:</strong> Можно создавать функции-"обертки" вокруг других функций, расширяя их возможности (например, добавляя логирование, мемоизацию кэша или debounce/throttle обертку).
  </li>
  <li>
    <strong>Каррирование и частичное применение:</strong> Трансформация функции с несколькими аргументами в цепочку вызванных функций с одним аргументом, что улучшает переиспользование логики.
  </li>
</ul>

<hr />

<h3>Важные нюансы и рекомендации</h3>

<p class="info info--orange">
  Функции, переданные как аргументы (callbacks), часто могут потерять контекст вызова (<strong>this</strong>). При использовании HOF внутри методов классов, убедитесь, что вы передаете контекст, используете стрелочные функции или привязываете объект через <code>bind</code>.
</p>

<p class="info info--blue">
  Самые известные классические HOF в JS — это методы массивов (<code>map</code>, <code>filter</code>, <code>reduce</code>, <code>forEach</code>, <code>some</code>, <code>every</code>), механизмы управления временем (<code>setTimeout</code>, <code>setInterval</code>), а также обработчики событий DOM, такие как <code>addEventListener</code>.
</p>

<h4>Декораторы и Мемоизация</h4>
<p>Продвинутый, но крайне практичный пример создания HOF — это реализация декоратора, например, мемоизации (наделение функции "памятью" сложных вычислений).</p>
<code class="code">
  function memoize(fn) {
    const cache = new Map();
    // Возвращаем новую функцию-обертку, в которой "замкнут" кеш (cache)
    return function(...args) {
      const key = JSON.stringify(args);
      if (cache.has(key)) {
        return cache.get(key); // Отдаем из кеша, не вызывая тяжелую оригинальную функцию
      }
      const result = fn(...args);
      cache.set(key, result);
      return result;
    };
  }

  const expensiveCalc = memoize((num) => {
    console.log('Computing...');
    return num * 1000;
  });

  expensiveCalc(10); // Выведет 'Computing...', вернет 10000
  expensiveCalc(10); // Ничего не выведет, вернет 10000 сразу из кеша `Map`
</code>

<h4>Связь с Execution Context и механизмом Замыканий (Closures)</h4>
<p>Когда HOF вызывает <code>return function() {...}</code>, возвращенная внутренняя функция "запоминает" переменных из своего родительского окружения (Lexical Environment), в котором она была создана. Это и есть механизм <span class="accent">Замыкания (Closure)</span>.</p>

<p>Даже когда внешняя (родительская) функция уже отработала, завершила свой цикл и её Execution Context (контекст выполнения) удалён из Call Stack (стека вызовов), возвращенная функция всё еще будет иметь доступ к переменным HOF через скрытое внутреннее свойство среды <code>[[Environment]]</code>. Именно благодаря этому работают приватные счётчики и кеш (как в функции memoize выше) — этот кеш живет в памяти сборщика мусора (Garbage Collector), спасаемый от удаления активным замыканием.</p>
