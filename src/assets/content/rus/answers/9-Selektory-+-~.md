<h3>Введение</h3>
<p><span class="accent">Комбинаторы</span> в CSS описывают отношение между различными селекторами, позволяя точно указывать, где элемент должен находиться в структуре DOM по отношению к другому элементу, чтобы к нему применились стили.</p>
<p class="info"><strong>TL;DR:</strong> Комбинаторы позволяют целиться в элементы на основе их родственных связей: <code>&gt;</code> для прямых детей, <code>+</code> для первого соседа, <code>~</code> для всех последующих соседей.</p>

<h3>Дочерний комбинатор (&gt;)</h3>
<p>Выбирает все элементы, которые являются <b>непосредственными детьми</b> указанного элемента. Он не выбирает потомков глубже (внуков, правнуков и т.д.).</p>

<code class="code">
  /* Выберет <li>, которые находятся сразу внутри <ul> */
  ul &gt; li {
    color: red;
  }
</code>

<h3>Соседний комбинатор (+)</h3>
<p>Выбирает <b>только один</b> следующий элемент, который идет <b>сразу же</b> после указанного элемента, если они имеют общего родителя (находятся на одном уровне).</p>

<code class="code">
  /* Выберет первый <p>, идущий ровно после <h1> */
  h1 + p {
    font-weight: bold;
  }
</code>

<h3>Общий соседний (родственный) комбинатор (~)</h3>
<p>Выбирает <b>все</b> последующие элементы на <b>том же уровне</b> вложенности, что и первый элемент, даже если между ними есть другие элементы.</p>

<code class="code">
  /* Выберет все <p>, которые идут после <h2> на одном с ним уровне */
  h2 ~ p {
    color: blue;
  }
</code>

<p class="info info--orange">Не путайте комбинатор потомков (пробел) и дочерний (<code>&gt;</code>). Пробел (например <code>div p</code>) выберет <b>все</b> <code>&lt;p&gt;</code> внутри <code>&lt;div&gt;</code> на любой глубине вложенности, а <code>&gt;</code> — только прямых детей первого уровня.</p>
