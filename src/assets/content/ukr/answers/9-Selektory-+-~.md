<h3>Вступ</h3>
<p><span class="accent">Комбінатори</span> в CSS описують відношення між різними селекторами, дозволяючи точно вказувати, де елемент повинен знаходитися в структурі DOM по відношенню до іншого елемента, щоб до нього застосувалися стилі.</p>
<p class="info"><strong>TL;DR:</strong> Комбінатори дозволяють цілитися в елементи на основі їхніх родинних зв'язків: <code>&gt;</code> для прямих дітей, <code>+</code> для першого сусіда, <code>~</code> для всіх наступних сусідів.</p>

<h3>Дочірній комбінатор (&gt;)</h3>
<p>Вибирає всі елементи, які є <b>безпосередніми дітьми</b> вказаного елемента. Він не вибирає нащадків глибше (онуків, правнуків тощо).</p>

<code class="code">
  /* Вибере <li>, які знаходяться відразу всередині <ul> */
  ul &gt; li {
    color: red;
  }
</code>

<h3>Сусідній комбінатор (+)</h3>
<p>Вибирає <b>тільки один</b> наступний елемент, який іде <b>відразу ж</b> після вказаного елемента, якщо вони мають спільного батька (знаходяться на одному рівні).</p>

<code class="code">
  /* Вибере перший <p>, що йде рівно після <h1> */
  h1 + p {
    font-weight: bold;
  }
</code>

<h3>Загальний сусідній (родинний) комбінатор (~)</h3>
<p>Вибирає <b>всі</b> наступні елементи на <b>тому ж рівні</b> вкладеності, що й перший елемент, навіть якщо між ними є інші елементи.</p>

<code class="code">
  /* Вибере всі <p>, які йдуть після <h2> на одному з ним рівні */
  h2 ~ p {
    color: blue;
  }
</code>

<p class="info info--orange">Не плутайте комбінатор нащадків (пробіл) і дочірній (<code>&gt;</code>). Пробіл (наприклад <code>div p</code>) вибере <b>всі</b> <code>&lt;p&gt;</code> всередині <code>&lt;div&gt;</code> на будь-якій глибині вкладеності, а <code>&gt;</code> — тільки прямих дітей першого рівня.</p>
