<h3>Навіщо потрібен Try...Catch?</h3>

<p><span class="accent">Try...Catch</span> — це конструкція в JavaScript, яка дозволяє обробляти помилки, що виникають під час виконання коду. Вона складається з двох основних блоків: <code>try</code> та <code>catch</code>.</p>

<p>Код без помилок — це ідеал, до якого ми прагнемо. Проте в реальному житті завжди є ймовірність виникнення помилок. Наприклад, сервер може впасти, користувач може ввести некоректні дані, або API може повернути битий JSON. Якщо не обробляти такі ситуації, виконання скрипту просто переривається, і користувач бачить «білий екран».</p>

<h3>Запобігання аварійній зупинці (Graceful Failure)</h3>
<p>Головне завдання — не дати застосунку «померти». Коли всередині блоку <code>try</code> виникає помилка, виконання коду в цьому блоці зупиняється, але управління передається в <code>catch</code>. Решта скрипту продовжує працювати.</p>

<p>Приклад із життя: Парсинг даних. Якщо дані прийдуть у невірному форматі, <code>JSON.parse</code> викине виключення. Без <code>try...catch</code> це «підвісить» фронтенд.</p>

<code class="code">
  try {
    const data = JSON.parse(responseFromServer); // Якщо тут помилка...
    process(data);
  } catch (error) {
    console.error("Помилка під час обробки даних:", error.message);
    showNotification("Вибачте, дані пошкоджені."); // Застосунок живе далі
  }
</code>

<h3>Блоки Try та Catch: Основи</h3>
<p>Блок <code>try</code> містить код, який може викликати помилку, а блок <code>catch</code> виконується, якщо в блоці <code>try</code> виникає помилка. У блоці <code>catch</code> ми можемо отримати об'єкт помилки та використати його для отримання інформації про те, що саме пішло не так.</p>

<h3>Блок finally: Чистота після бурі</h3>
<p>Є завдання, які мають бути виконані завжди, незалежно від того, сталася помилка чи ні. Для цього потрібен <code>finally</code>.</p>

<p>Приклади використання:</p>
<ul>
  <li>Закриття з'єднань.</li>
  <li>Вимкнення індикатора завантаження (spinner). Тобі в будь-якому разі потрібно прибрати «крутилку» з екрана, чи завантажилися дані, чи впали з помилкою.</li>
</ul>

<code class="code">
  try {
    showSpinner();
    const data = await fetchData();
    process(data);
  } catch (error) {
    console.error("Помилка під час завантаження даних:", error.message);
    showNotification("Не вдалося завантажити дані.");
  } finally {
    hideSpinner(); // Прибираємо крутилку в будь-якому разі
  }
</code>

<h3>Поради щодо використання:</h3>
<p><strong>Не «ковтай» помилки:</strong> Ніколи не залишай <code>catch (e) {}</code> порожнім. Якщо ти не знаєш, що робити з помилкою, хоча б виведи її в консоль. Інакше налагодження перетвориться на пекло.</p>

<p><strong>Будь специфічним:</strong> Не огортай увесь код в один гігантський <code>try...catch</code>. Огортай тільки ті ділянки, де помилка ймовірна (мережеві запити, робота з DOM, складні обчислення).</p>

<p><strong>Викидай свої помилки:</strong> Ти можеш сам генерувати виключення за допомогою <code>throw new Error('Something went wrong')</code>. Це чудовий спосіб передати сигнал про проблему з глибин бізнес-логіки наверх, до UI-компонента.</p>
